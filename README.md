# Fernrohr

A native Kubernetes cluster GUI in Rust - broadly a FreeLens/OpenLens equivalent with k9s-inspired
keyboard-first workflows and multi-window / multi-panel support.

This is a meta-repository: the application code lives in the `App` submodule
([pilgrimagesoftware/Fernrohr-App](https://github.com/pilgrimagesoftware/Fernrohr-App)). This repo
holds the OpenSpec change proposals and specs that drive that code's implementation.

See [`docs/architecture.md`](docs/architecture.md) for the tech stack and architecture decisions.
